## 1. 使用说明

本矩阵覆盖 V3.12 正文、修订记录和指令汇总中出现的全部命令。字段事实优先取命令专节；汇总表、专节、示例、点检表和历史实现不一致时引用 `AHTT-V3.12-事实台账.md` 的冲突编号，不在矩阵中自行裁决。

通用帧固定部分：

```text
帧头1 + 总长度2 + 协议版本? + 设备编号5 + 流水号2 + 指令1 + 参数N + CRC2
```

协议版本长度存在 C-001，因此所有“固定总帧长”在 C-001 关闭前只作为待核对值。除特别说明外，多字节数值低字节在前；单号范围 1～10000，流水号范围 1～60000。

当前架构缩写：

| 缩写 | 目标位置/职责 |
|---|---|
| T | `Asw_IotProtoAHTTTypes.h`：命令、字段、上下文、控制项 |
| S | `Asw_IotProtoAHTTSend.c/.h`：上行组包、应答组包和发送控制 |
| R | `Asw_IotProtoAHTTRecv.c/.h`：帧校验、下行解析、应答匹配和超时 |
| M | `Asw_IotProtoAHTTM.c/.h`：四态状态机、周期调度和业务仲裁 |
| P | `Asw_PlatM`/`FrameQueue`/网络管理：平台接入和 TCP 数据通道 |
| N | `MS_Nvm`/`MSNvmPlatPrivateParam_Union`/订单块：持久化 |
| C | `Asw_ChargeIf`、`Asw_Monitor`、当前充电/故障接口 |
| TM | `SS_Tm`：时间同步 |

“点检”列来自 `reference/协议点检表.xlsx`，`YES` 仍是候选范围，并非本轮用户已确认的正式范围。

## 7. 共同验证基线

每个进入实现范围的命令至少覆盖：

| 类别 | 用例 |
|---|---|
| 正常 | 最小值、典型值、最大值、请求/应答关联、黄金报文字节一致 |
| 帧边界 | 半包、粘包、连续多帧、异常帧后正常帧、缓冲区上限 |
| 合法性 | 错帧头、错版本、错声明长度、错CRC、错设备号、未知命令 |
| 参数 | 固定/可变长度、数组个数、字段范围、枚举、端序、单位、溢出 |
| 业务 | 前置状态不满足、未插枪、通道故障、重复单号、重复应答、跨端口输入 |
| 时序 | 平台不应答、重试上限、最终失败动作、断线重连、复位和掉电恢复 |
| 持久化 | 默认值、重复设置、写入失败、版本兼容、写入次数和掉电一致性 |
| 安全 | 本地保护优先、失败安全、日志脱敏、OTA鉴权/签名/回滚（若适用） |
