# AHTT 任务交付模板

只读取与当前任务类型对应的章节；不要机械输出所有模板。

## 协议命令分析

```markdown
### 命令：<名称与命令字>
- 协议依据：<章节/表格/页码>
- 方向与触发：<设备→平台或平台→设备；触发条件>
- 帧与字段：<长度、端序、单位、范围、可选条件>
- 应答与关联：<流水号、单号、匹配命令>
- 异常行为：<非法长度、CRC、设备号、重复、超时、重试>
- 当前架构映射：<Types/Send/Recv/M/PlatM/NVM/业务接口>
- GN 同构映射：<GN 符号→AHTT 符号；是否仅替换协议标识；差异原因>
- 旧实现参考：<文件、符号、可复用经验、不可照搬点>
- 状态：[CONFIRMED]/[OBSERVED]/[ASSUMPTION]/[TBD]/[TBC]/[CONFLICT]
```

## 代码修改方案

```markdown
### 方案：<标题>
**目标**：<一句话>
**改动文件**：<精确路径>

#### 改动详情
- 现状与问题：<证据>
- 新数据流/状态转换：<入口到出口>
- 具体改动：<新旧对比或伪代码>
- GN 对照：<文件/函数/类型/变量/状态机映射；全部非同构点及原因>
- 校验边界：<平台输入校验；内部判断对应的 GN 位置；新增判断的可达失败路径>
- 异常与兼容：<超时、重试、NVM、升级、并发>
- 验证：<报文向量、构建、板端、平台>

请确认是否按此方案执行？
```

## 单命令验证矩阵

| 类别 | 最小用例 |
|---|---|
| 正常 | 最小值、典型值、最大值、黄金报文字节一致 |
| 帧边界 | 半包、粘包、连续多帧、异常帧后正常帧 |
| 合法性 | 错帧头、错版本、错长度、错 CRC、错设备号、未知命令 |
| 业务 | 前置状态不满足、重复单号、重复应答、跨端口输入 |
| 时序 | 平台不应答、超时、重试上限、断线重连、复位恢复 |
| 资源 | 缓冲区上限、循环执行时间、任务阻塞、RAM/Flash 增量 |

- 待平台验证：<场景与通过标准>
- 未关闭问题：<TBD/TBC/CONFLICT>
- 文档回写：<命令矩阵、向量、联调记录>
